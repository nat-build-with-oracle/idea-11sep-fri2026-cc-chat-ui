# v26.9.13-alpha.1324 — Claude-only workspace

**Source alpha · 13 September 2026 · Asia/Bangkok CalVer**

## Highlights

- Restore normal Claude Code authentication after the GLM experiment: only Sonnet, Opus, and Haiku are offered, and managed Claude processes no longer inherit third-party provider/endpoint/model overrides.
- Preserve saved non-Claude conversations as read-only, including native-session duplicates. No conversation migration or deletion is part of this release.
- Add explicit Haiku/Sonnet → Opus session-name suggestions, with bounded text excerpts, no-tools/stateless calls, cancellation, and conflict-checked local display aliases.
- Restore Command-K project/Oracle search and keep Timeline links aligned with the selected backend and current return route.
- Add optional authenticated NetBird access and a Timeline bridge; retain exact host/origin checks and document the risks of explicit `NO_AUTH` mode.
- Harden installed-app update recipes with process ownership, idle-state checks, awaited shutdown, restarted-listener verification, backups, and guarded rollback.
- Pin a release CalVer with `CC_CHAT_BUILD_VERSION` while retaining truthful build timestamps and Git revisions. Align npm, Tauri, and Cargo version metadata.
- Publish a [complete visual tour with 20 screenshots](https://github.com/nat-build-with-oracle/idea-11sep-fri2026-cc-chat-ui/blob/v26.9.13-alpha.1324/docs/tutorials/claude-only-complete-tour.md), using only synthetic conversations and fake model responses.

## Install from source

Check out this release and install its locked dependencies:

```sh
git checkout v26.9.13-alpha.1324
npm ci
CC_CHAT_BUILD_VERSION=v26.9.13-alpha.1324 npm run build
npm start
```

Open **http://127.0.0.1:4318/#/new**. Use your own normal Claude Code login. If an installed ARRA app already owns port 4318, do not start a competing backend; see the [safe installed-app updater](https://github.com/nat-build-with-oracle/idea-11sep-fri2026-cc-chat-ui/blob/v26.9.13-alpha.1324/docs/claude-code-and-session-names.md).

## Distribution and verification limits

- **No prebuilt DMG is attached.** Cached installers were stale, signing/notarization is not configured, and redistribution of bundled third-party runtime components has not been cleared. This is a source release, not a signed macOS installer.
- Publishing this tag does **not** deploy the Cloudflare frontend or replace an already installed local application. Their displayed versions may therefore differ until explicitly updated.
- The tutorial uses fixture-only browser captures from build `v26.9.13-alpha.1251`. Its fake runner does not write real Claude JSONL, so the illustrated sync badge is not proof of live history synchronization. Images show complete app windows, not stitched virtualized histories.
- VPN lifecycle failure paths were tested with mocks/temp files. This release process did not change the running app's authentication settings, stop Claude/tmux writers, or test a new connection from another VPN device.
- AI naming makes two charged Claude calls in the real backend. Generated titles are never applied automatically.
- Full access bypasses permission prompts. Use trusted repositories; never expose an unauthenticated backend to the public internet.
